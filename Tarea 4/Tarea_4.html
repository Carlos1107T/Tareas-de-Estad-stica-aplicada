Tarea 4. Estimación por el Método de Momentos

Suponiendo dada una muestra aleatoria de tamaño \(n\) para cada una de las siguientes distribuciones realiza lo siguiente:

  1. Encuentra el estimador para \(\theta\) por el método de momentos.

  2. Verifica si es insesgado y/o asintóticamente insesgado.

    En este inciso será de utilidad recordar la esperanza de la media muestral:

\[E(\overline{X}) = E\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n}\sum_{i=1}^n E(X_i) = \frac{1}{n} n E(X) = E(X).\]

  1. Calcula la varianza del estimador.

    Es conveniente recordar algunas propiedades de la varianza que se enuncian en la siguiente proposición:

Proposición 1 Sean \(X\) y \(Y\) dos variables aleatorias con varianza finita y sea \(c\) una constante, entonces:

  1. \(Var(c)=0\).
  2. \(Var(cX) = c^2 Var(X)\).
  3. \(Var(X+c) = Var(X)\).
  4. \(Var(X) = E(X^2) - [E(X)]^2\).
  5. \(Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y)\), donde \[Cov(X,Y) = E[(X - E(X))(Y - E(Y))]\] es la covarianza entre \(X\) y \(Y\). Si \(X\) y \(Y\) son independientes, entonces \(Cov(X,Y) = 0\) y por lo tanto \(Var(X+Y) = Var(X) + Var(Y)\).

Además, dado que en una muestra aleatoria consideramos variables aleatorias independientes:

\[Var{\overline{X}} = Var\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n^2}Var\left(\sum_{i=1}^n X_i\right) = \frac{1}{n^2}\sum_{i=1}^n Var(X_i) = \frac{1}{n^2} n Var(X) = \frac{Var(X)}{n}.\]

Ejercicio 1 Para \(0 < \theta < 4\), consideramos la función de probabilidad:

\[\begin{equation} f(x;\theta) = \begin{cases} \theta/4 & \text{si } x = 1, \\ 1 - \theta/4 & \text{si } x = 2, \\ 0 & \text{en otro caso.} \end{cases} \end{equation}\]

  • a) Estimador
  • b) Insesgamiento
  • c) Varianza
  • d) ECM
  • e) Simulación
  • f) Convergencia

Encontramos el estimador para \(\theta\) por el método de momentos.

Primero calculamos la esperanza de la variable aleatoria \(X\):

\[\begin{equation} E(X) = \sum_x x f(x;\theta) = (1)(\theta /4) + (2)(1-\theta/4) = 2 - \frac{1\theta}{4} \end{equation}\]

Luego, igualamos la esperanza muestral a la esperanza teórica para encontrar el estimador por el método de momentos:

\[\begin{equation} \overline{X} = 2 - \frac{1\hat\theta}{4} \implies \hat\theta = (4) (2 - \bar{X}) \end{equation}\]

Verificamos si es insesgado y/o asintóticamente insesgado.

\[\begin{equation} E(\hat{\theta}) = E\left(4(2 - \overline{X})\right) = 4\left(2 - E(\overline{X})\right) = 4\left(2 - E(X)\right) = 4\left(2 - \left(2 - \frac{\theta}{4}\right)\right) = 4\left(\frac{\theta}{4}\right) = \theta \end{equation}\]

Luego, el estimador es insesgado y por lo tanto, asintóticamente insesgado.

\[\begin{equation} Var(\hat{\theta}) = Var\left(4(2 - \overline{X})\right) = 16Var(2 - \overline{X}) = 16Var(\overline{X}) = 16\frac{Var(X)}{n} \end{equation}\]

Para calcular \(Var(X)\) utilizamos la igualdad \(Var(X) = E(X^2) - [E(X)]^2\) y para ello, inicialmente calculamos \(E(X^2)\):

\[\begin{equation} E(X^2) = \sum_x x^2 f(x;\theta) = (1)^2(\theta/4) + (2)^2(1 - \theta/4) = \frac{\theta}{4} + 4(1 - \theta/4) = 4 - \frac{3\theta}{4} \end{equation}\]

Luego, calculamos la varianza de \(X\):

\[\begin{equation} Var(X) = E(X^2) - [E(X)]^2 = \left(4 - \frac{3\theta}{4}\right) - \left(2 - \frac{\theta}{4}\right)^2 = \frac{4\theta - \theta^2}{16} \end{equation}\]

Finalmente, sustituimos \(Var(X)\) en la expresión de \(Var(\hat{\theta})\):

\[\begin{equation} Var(\hat{\theta}) = 16\frac{1}{n}\left(\frac{4\theta - \theta^2}{16}\right) = \frac{4\theta - \theta^2}{n} \end{equation}\]

Calculamos el error cuadrático medio (ECM).

Dado que el estimador es insesgado, el ECM es igual a la varianza:

\[\begin{equation} ECM(\hat{\theta}) = Var(\hat{\theta}) = \frac{4\theta - \theta^2}{n} \end{equation}\]

Ejercicio 2 Para \(0 < \theta < 6/5\), consideramos la función de probabilidad:

\[\begin{equation} f(x;\theta) = \begin{cases} \theta/2 & \text{si } x = -1, \\ \theta/3 & \text{si } x = 0, \\ 1-5\theta/6 & \text{si } x = 1, \\ 0 & \text{en otro caso.} \end{cases} \end{equation}\]

  • a) Estimador
  • b) Insesgamiento
  • c) Varianza
  • d) ECM
  • e) Simulación
  • f) Convergencia

Encontramos el estimador para \(\theta\) por el método de momentos.

Primero calculamos la esperanza de la variable aleatoria \(X\):

\[\begin{equation} E(X) = \sum_x x f(x;\theta) = (-1)(\theta /2) + (0)(\theta/3) + (1)(1-5\theta/6) = 1 - \frac{4\theta}{3} \end{equation}\]

Luego, igualamos la esperanza muestral a la esperanza teórica para encontrar el estimador por el método de momentos:

\[\begin{equation} \overline{X} = 1 - \frac{4\hat\theta}{3} \implies \hat\theta = \frac{3(1 - \bar{X})}{4} \end{equation}\]

Verificamos si es insesgado y/o asintóticamente insesgado.

\[\begin{equation} E(\hat\theta) = E\left(\frac{3(1 - \overline{X})}{4}\right) = \frac{3}{4}(1 - E(\overline{X})) = \frac{3}{4}(1 - E(X)) = \frac{3}{4}\left(1 - \left(1 - \frac{4\theta}{3}\right)\right) = \theta \end{equation}\]

Luego, el estimador es insesgado y por lo tanto, asintóticamente insesgado.

Calculamos la varianza del estimador.

\[\begin{equation} Var(\hat\theta) = Var\left(\frac{3(1 - \overline{X})}{4}\right) = \left(\frac{3}{4}\right)^2 Var(1 - \overline{X}) = \left(\frac{3}{4}\right)^2 Var(\overline{X}) = \left(\frac{3}{4}\right)^2 \frac{Var(X)}{n} \end{equation}\]

Para calcular \(Var(X)\) utilizamos la igualdad \(Var(X) = E(X^2) - [E(X)]^2\) y para ello, inicialmente calculamos \(E(X^2)\):

\[\begin{equation} E(X^2) = \sum_x x^2 f(x;\theta) = (-1)^2(\theta/2) + (0)^2(\theta/3) + (1)^2(1 - 5\theta/6) = \frac{\theta}{2} + 1 - \frac{5\theta}{6} = 1 - \frac{\theta}{3} \end{equation}\]

Luego, calculamos la varianza de \(X\):

\[\begin{equation} Var(X) = E(X^2) - [E(X)]^2 = \left(1 - \frac{\theta}{3}\right) - \left(1 - \frac{4\theta}{3}\right)^2 = \frac{-\theta^2 + 6\theta}{9} \end{equation}\]

Finalmente, sustituimos \(Var(X)\) en la expresión de \(Var(\hat\theta)\):

\[\begin{equation} Var(\hat\theta) = \left(\frac{3}{4}\right)^2 \frac{1}{n} \frac{-\theta^2 + 6\theta}{9} = \frac{-\theta^2 + 6\theta}{16n} \end{equation}\]

Calculamos el error cuadrático medio (ECM).

Dado que el estimador es insesgado, el ECM es igual a la varianza:

\[\begin{equation} ECM(\hat\theta) = Var(\hat\theta) = \frac{-\theta^2 + 6\theta}{16n} \end{equation}\]

Ejercicio 3 Para \(0 < \theta < 3/2\), consideramos la función de probabilidad:

\[\begin{equation} f(x;\theta) = \begin{cases} \theta/3 & \text{si } x = 0, \\ 1-2\theta/3 & \text{si } x = 1, \\ \theta/3 & \text{si } x = 2, \\ 0 & \text{en otro caso.} \end{cases} \end{equation}\]

  • a) Estimador
  • b) Insesgamiento
  • c) Varianza
  • d) ECM
  • e) Simulación
  • f) Convergencia

Encontramos el estimador para \(\theta\) por el método de momentos.

Primero calculamos la esperanza de la variable aleatoria \(X\):

\[\begin{equation} E(X) = \sum_x x f(x; \theta) = (0)(\theta/3) + (1)(1 - 2\theta/3) + (2)(\theta/3) = 1 \end{equation}\]

: La esperanza no depende de \(\theta\), por lo que necesitamos usar el segundo momento.

\[\begin{equation} E(X^2) = \sum_x x^2 f(x; \theta) = (0)^2(\theta/3) + (1)^2(1 - 2\theta/3) + (2)^2(\theta/3) = 1 + \frac{2\theta}{3} \end{equation}\]

Igualamos el segundo momento muestral al teórico:

\[\begin{equation} \frac{1}{n}\sum_{i=1}^n X_i^2 = 1 + \frac{2\hat{\theta}}{3} \implies \hat{\theta} = \frac{3}{2}\left(\frac{1}{n}\sum_{i=1}^n X_i^2 - 1\right) \end{equation}\]

Verificamos si es insesgado y/o asintóticamente insesgado.

\[\begin{equation} E(\hat{\theta}) = E\left(\frac{3}{2}\left(\frac{1}{n}\sum_{i=1}^n X_i^2 - 1\right)\right) = \frac{3}{2}\left(E\left(\frac{1}{n}\sum_{i=1}^n X_i^2\right) - 1\right) = \frac{3}{2}\left(E(X^2) - 1\right) = \frac{3}{2}\left(\left(1 + \frac{2\theta}{3}\right) - 1\right) = \frac{3}{2}\left(\frac{2\theta}{3}\right) = \theta \end{equation}\]

Luego, el estimador es insesgado y por lo tanto, asintóticamente insesgado.

Calculamos la varianza del estimador.

\[\begin{equation} Var(\hat{\theta}) = Var\left(\frac{3}{2}\left(\frac{1}{n}\sum_{i=1}^n X_i^2 - 1\right)\right) = \left(\frac{3}{2}\right)^2 Var\left(\frac{1}{n}\sum_{i=1}^n X_i^2\right) = \frac{9}{4} \cdot \frac{1}{n} Var(X^2) \end{equation}\]

Para calcular \(Var(X^2)\) utilizamos la igualdad \(Var(X^2) = E(X^4) - [E(X^2)]^2\) y para ello, inicialmente calculamos \(E(X^4)\):

\[\begin{equation} E(X^4) = \sum_x x^4 f(x;\theta) = (0)^4(\theta/3) + (1)^4(1 - 2\theta/3) + (2)^4(\theta/3) = 1 + \frac{14\theta}{3} \end{equation}\]

Luego, calculamos la varianza de \(X^2\):

\[\begin{equation} Var(X^2) = E(X^4) - [E(X^2)]^2 = \left(1 + \frac{14\theta}{3}\right) - \left(1 + \frac{2\theta}{3}\right)^2 = \frac{10\theta}{3} - \frac{4\theta^2}{9} \end{equation}\]

Finalmente, sustituimos \(Var(X^2)\) en la expresión de \(Var(\hat{\theta})\):

\[\begin{equation} Var(\hat{\theta}) = \frac{9}{4} \cdot \frac{1}{n} \left(\frac{10\theta}{3} - \frac{4\theta^2}{9}\right) = \frac{15\theta - 2\theta^2}{2n} \end{equation}\]

Calculamos el error cuadrático medio (ECM).

Dado que el estimador es insesgado, el ECM es igual a la varianza:

\[\begin{equation} ECM(\hat{\theta}) = Var(\hat{\theta}) = \frac{15\theta - 2\theta^2}{2n} \end{equation}\]

Ejercicio 4 Para \(\theta \in \mathbb{N}\), consideramos la función de probabilidad:

\[\begin{equation} f(x;\theta) = \begin{cases} \frac{2x}{\theta(\theta+1)} & \text{si } x = 1, 2, \ldots, \theta, \\ 0 & \text{en otro caso.} \end{cases} \end{equation}\]

  • a) Estimador
  • b) Insesgamiento
  • c) Varianza
  • d) ECM
  • e) Simulación
  • f) Convergencia

Calculamos el estimador para \(\theta\).

Inicialmente calculamos la esperanza:

\[\begin{eqnarray} E(X) & = & \sum_{x=1}^{\theta} x f(x;\theta)\\ & = & \frac{2}{\theta(\theta +1)} \sum_{x=1}^\theta x^2\\ & = & \frac{2\theta +1}{3} \end{eqnarray}\]

Igualando \(E(X)\) con la media muestral tenemos:

\[\begin{equation} E(X) = \overline{X} \implies \frac{2\theta +1}{3} = \overline{X} \implies \hat{\theta} = \frac{3\bar{X}-1}{2} \end{equation}\]

Verificamos si es insesgado y/o asintóticamente insesgado.

\[\begin{equation} E(\hat{\theta}) = E\left(\frac{3\bar{X} - 1}{2}\right) = \frac{3}{2}E(\bar{X}) - \frac{1}{2} = \frac{3}{2}E(X) - \frac{1}{2} = \frac{3}{2}\left(\frac{2\theta + 1}{3}\right) - \frac{1}{2} = \theta + \frac{1}{2} - \frac{1}{2} = \theta \end{equation}\]

Luego, el estimador es insesgado y por lo tanto, asintóticamente insesgado.

Calculamos la varianza del estimador.

\[\begin{equation} Var(\hat{\theta}) = Var\left(\frac{3\bar{X} - 1}{2}\right) = \left(\frac{3}{2}\right)^2 Var(\bar{X}) = \frac{9}{4} \cdot \frac{Var(X)}{n} \end{equation}\]

Para calcular \(Var(X)\) utilizamos la igualdad \(Var(X) = E(X^2) - [E(X)]^2\) y para ello, inicialmente calculamos \(E(X^2)\):

\[\begin{equation} E(X^2) = \sum_x x^2 f(x;\theta) = \sum_{x=1}^\theta x^2 \cdot \frac{2x}{\theta(\theta + 1)} = \frac{2}{\theta(\theta + 1)} \sum_{x=1}^\theta x^3 = \frac{2}{\theta(\theta + 1)} \cdot \left[\frac{\theta(\theta + 1)}{2}\right]^2 = \frac{\theta(\theta + 1)}{2} \end{equation}\]

Luego, calculamos la varianza de \(X\):

\[\begin{equation} Var(X) = E(X^2) - [E(X)]^2 = \frac{\theta(\theta + 1)}{2} - \left(\frac{2\theta + 1}{3}\right)^2 = \frac{\theta^2 + \theta - 2}{18} \end{equation}\]

Finalmente, sustituimos \(Var(X)\) en la expresión de \(Var(\hat{\theta})\):

\[\begin{equation} Var(\hat{\theta}) = \frac{9}{4} \cdot \frac{1}{n} \cdot \frac{\theta^2 + \theta - 2}{18} = \frac{\theta^2 + \theta - 2}{8n} \end{equation}\]

Calculamos el error cuadrático medio (ECM).

Dado que el estimador es insesgado, el ECM es igual a la varianza:

\[\begin{equation} ECM(\hat{\theta}) = Var(\hat{\theta}) = \frac{\theta^2 + \theta - 2}{8n} \end{equation}\]

Para poder generar las muestras aleatorias de las distribuciones continuas de los siguientes ejercicios, es necesario enunciar el siguiente teorema:

Teorema 1 Si \(X\) es una variable aleatoria continua con función de distribución acumulada \(F_X(x)\), entonces la variable aleatoria \(U = F_X(X)\) tiene una distribución uniforme en el intervalo \((0,1)\). Además, si \(U \sim unif(0,1)\), entonces la variable aleatoria \(X = F_X^{-1}(U)\) tiene la misma distribución que \(X\).

Para poder aplicar el teorema de inversión, es necesario encontrar la función de distribución acumulada y su inversa. Para que esto último sea posible, es necesario que la función de distribución acumulada sea estrictamente creciente.

Ejercicio 5 Para \(\theta >0\), consideramos la función de densidad:

\[\begin{equation} f(x;\theta) = \begin{cases} \frac{2x}{\theta^2} & \text{si } 0\leq x \leq \theta \\ 0 & \text{en otro caso.} \end{cases} \end{equation}\]

  • a) Estimador
  • b) Insesgamiento
  • c) Varianza
  • d) ECM
  • e) Simulación
  • f) Convergencia

Encontramos el estimador para \(\theta\) por el método de momentos.

Primero calculamos la esperanza de la variable aleatoria \(X\):

\[\begin{eqnarray} E(X) & = & \int_{-\infty}^{\infty} x f(x;\theta) dx \\ & = & \int_0^{\theta} x \frac{2x}{\theta^2} dx \\ & = & \frac{2}{\theta^2} \int_0^{\theta} x^2 dx \\ & = & \frac{2}{\theta^2} \left[\frac{x^3}{3}\right]_0^{\theta} \\ & = & \frac{2\theta}{3} \end{eqnarray}\]

Ahora igualamos la esperanza muestral a la esperanza teórica para encontrar el estimador por el método de momentos:

\[\begin{equation} \overline{X} = \frac{2\hat\theta}{3} \implies \hat\theta = \frac{3\overline{X}}{2} \end{equation}\]

Verificamos si es insesgado y/o asintóticamente insesgado.

\[\begin{equation} E(\hat\theta) = E\left(\frac{3\overline{X}}{2}\right) = \frac{3}{2}E(\overline{X}) = \frac{3}{2}E(X) = \frac{3}{2}\left(\frac{2\theta}{3}\right) = \theta \end{equation}\]

Entonces, el estimador es insesgado y por lo tanto, asintóticamente insesgado.

Calculamos la varianza del estimador.

\[\begin{equation} Var(\hat\theta) = Var\left(\frac{3\overline{X}}{2}\right) = \left(\frac{3}{2}\right)^2 Var(\overline{X}) = \left(\frac{3}{2}\right)^2 \frac{Var(X)}{n} \end{equation}\]

Para calcular \(Var(X)\) utilizamos la igualdad \(Var(X) = E(X^2) - [E(X)]^2\) y para ello, inicialmente calculamos \(E(X^2)\):

\[\begin{eqnarray} E(X^2) & = & \int_{-\infty}^{\infty} x^2 f(x;\theta) dx \\ & = & \int_0^{\theta} x^2 \frac{2x}{\theta^2} dx \\ & = & \frac{2}{\theta^2} \int_0^{\theta} x^3 dx \\ & = & \frac{2}{\theta^2} \left[\frac{x^4}{4}\right]_0^{\theta} \\ & = & \frac{\theta^2}{2} \end{eqnarray}\]

Luego, calculamos la varianza de \(X\):

\[\begin{equation} Var(X) = E(X^2) - [E(X)]^2 = \frac{\theta^2}{2} - \left(\frac{2\theta}{3}\right)^2 = \frac{\theta^2}{18} \end{equation}\]

Finalmente, sustituimos \(Var(X)\) en la expresión de \(Var(\hat\theta)\):

\[\begin{equation} Var(\hat\theta) = \left(\frac{3}{2}\right)^2 \frac{1}{n}\frac{\theta^2}{18} = \frac{\theta^2}{8n} \end{equation}\]

Calculamos el error cuadrático medio (ECM).

Dado que el estimador es insesgado, el ECM es igual a la varianza:

\[\begin{equation} ECM(\hat\theta) = Var(\hat\theta) = \frac{\theta^2}{8n} \end{equation}\]

En este caso hay que calcular la función de distribución (CDF o probabilidad acumulada)

\[\begin{eqnarray} F_X(x;\theta) & = & \int_{-\infty}^{x} f(t;\theta) dt \\ & = & \int_0^{x} \frac{2t}{\theta^2} dt \\ & = & \frac{2}{\theta^2} \left[\frac{t^2}{2}\right]_0^{x} \\ & = & \frac{x^2}{\theta^2}, \quad 0 \leq x \leq \theta \end{eqnarray}\]

Observamos que \(F_X(x;\theta)\) es estrictamente creciente en el intervalo \((0, \theta)\) y por lo tanto, podemos encontrar su inversa, igualando \(U=F_X(x,\theta)\) donde \(U \sim unif(0,1)\), tenemos

\[\begin{equation} U = \frac{x^2}{\theta^2} \implies x = \theta \sqrt{U} \end{equation}\]

Luego, la variable aleatoria \(X=F_X^{-1}(U)=\theta \sqrt{U}\) tiene la misma distribución que \(X\).

\[\begin{equation} f(x;\theta) = \begin{cases} e^{-(x-\theta)} & \text{si } \theta \leq x < \infty \\ 0 & \text{en otro caso.} \end{cases} \end{equation}\]

  • a) Estimador
  • b) Insesgamiento
  • c) Varianza
  • d) ECM
  • e) Simulación
  • f) Convergencia

Encontramos el estimador para \(\theta\) por el método de momentos.

Primero calculamos la esperanza de la variable aleatoria \(X\):

\[\begin{eqnarray} E(X) & = & \int_{-\infty}^{\infty} x f(x;\theta) dx \\ & = & \int_{\theta}^{\infty} x e^{-(x-\theta)} dx \\ & = & \int_{0}^{\infty} (u + \theta) e^{-u} du \\ & = & \int_{0}^{\infty} u e^{-u} du + \theta \int_{0}^{\infty} e^{-u} du \\ & = & 1 + \theta \end{eqnarray}\]

Ahora igualamos la esperanza muestral a la esperanza teórica para encontrar el estimador por el método de momentos:

\[\begin{equation} \overline{X} = 1 + \hat\theta \implies \hat\theta = \overline{X} - 1 \end{equation}\]

Verificamos si es insesgado y/o asintóticamente insesgado.

\[\begin{equation} E(\hat\theta) = E\left(\overline{X} - 1\right) = E(\overline{X}) - 1 = E(X) - 1 = (1 + \theta) - 1 = \theta \end{equation}\]

Entonces, el estimador es insesgado y por lo tanto, asintóticamente insesgado.

Calculamos la varianza del estimador.

\[\begin{equation} Var(\hat\theta) = Var\left(\overline{X} - 1\right) = Var(\overline{X}) = \frac{Var(X)}{n} \end{equation}\]

Para calcular \(Var(X)\) utilizamos la igualdad \(Var(X) = E(X^2) - [E(X)]^2\) y para ello, inicialmente calculamos \(E(X^2)\):

\[\begin{eqnarray} E(X^2) & = & \int_{-\infty}^{\infty} x^2 f(x;\theta) dx \\ & = & \int_{\theta}^{\infty} x^2 e^{-(x-\theta)} dx \\ & = & \int_{0}^{\infty} (u + \theta)^2 e^{-u} du \\ & = & \int_{0}^{\infty} (u^2 + 2\theta u + \theta^2) e^{-u} du \\ & = & 2 + 2\theta + \theta^2 \end{eqnarray}\]

Luego, calculamos la varianza de \(X\):

\[\begin{equation} Var(X) = E(X^2) - [E(X)]^2 = (2 + 2\theta + \theta^2) - (1 + \theta)^2 = 1 \end{equation}\]

Finalmente, sustituimos \(Var(X)\) en la expresión de \(Var(\hat\theta)\):

\[\begin{equation} Var(\hat\theta) = \frac{1}{n} \end{equation}\]

Calculamos el error cuadrático medio (ECM).

Dado que el estimador es insesgado, el ECM es igual a la varianza:

\[\begin{equation} ECM(\hat\theta) = Var(\hat\theta) = \frac{1}{n} \end{equation}\]

Observamos que \(F_X(x;\theta)\) es estrictamente creciente en el intervalo \((\theta, \infty)\) y por lo tanto, podemos encontrar su inversa, igualando \(U=F_X(x,\theta)\) donde \(U \sim unif(0,1)\), tenemos

Ejercicio 7 Para \(\theta >0\), consideramos la función de densidad:

\[\begin{equation} f(x;\theta) = \begin{cases} \theta x^{\theta-1} & \text{si } 0< x < 1 \\ 0 & \text{en otro caso.} \end{cases} \end{equation}\]

  • a) Estimador
  • b) Insesgamiento
  • c) Varianza
  • e) Simulación
  • f) Convergencia

Encontramos el estimador para \(\theta\) por el método de momentos.

Primero calculamos la esperanza de la variable aleatoria \(X\):

\[\begin{eqnarray} E(X) & = & \int_{-\infty}^{\infty} x f(x;\theta) dx \\ & = & \int_{0}^{1} x \cdot \theta x^{\theta-1} dx \\ & = & \theta \int_{0}^{1} x^{\theta} dx \\ & = & \theta \left[\frac{x^{\theta+1}}{\theta+1}\right]_{0}^{1} \\ & = & \frac{\theta}{\theta+1} \end{eqnarray}\]

Ahora igualamos la esperanza muestral a la esperanza teórica para encontrar el estimador por el método de momentos:

\[\begin{equation} \overline{X} = \frac{\hat\theta}{\hat\theta + 1} \implies \hat\theta = \frac{\overline{X}}{1 - \overline{X}} \end{equation}\]

Verificamos si es insesgado y/o asintóticamente insesgado.

\[\begin{equation} E(\hat\theta) = E\left(\frac{\overline{X}}{1 - \overline{X}}\right) \neq \frac{E(\overline{X})}{1 - E(\overline{X})} = \frac{\frac{\theta}{\theta+1}}{1 - \frac{\theta}{\theta+1}} = \frac{\frac{\theta}{\theta+1}}{\frac{1}{\theta+1}} = \theta \end{equation}\]

Entonces, el estimador NO es insesgado pero es asintóticamente insesgado (consistente).

Calculamos la varianza del estimador.

\[\begin{equation} Var(\hat\theta) = Var\left(\frac{\overline{X}}{1 - \overline{X}}\right) \end{equation}\]

El cálculo exacto de la varianza es complejo debido a la forma no lineal del estimador. Para calcular \(Var(X)\) utilizamos la igualdad \(Var(X) = E(X^2) - [E(X)]^2\) y para ello, inicialmente calculamos \(E(X^2)\):

\[\begin{eqnarray} E(X^2) & = & \int_{-\infty}^{\infty} x^2 f(x;\theta) dx \\ & = & \int_{0}^{1} x^2 \cdot \theta x^{\theta-1} dx \\ & = & \theta \int_{0}^{1} x^{\theta+1} dx \\ & = & \theta \left[\frac{x^{\theta+2}}{\theta+2}\right]_{0}^{1} \\ & = & \frac{\theta}{\theta+2} \end{eqnarray}\]

Luego, calculamos la varianza de \(X\):

\[\begin{equation} Var(X) = E(X^2) - [E(X)]^2 = \frac{\theta}{\theta+2} - \left(\frac{\theta}{\theta+1}\right)^2 = \frac{\theta}{(\theta+1)^2(\theta+2)} \end{equation}\]

Sin embargo, debido a la no linealidad del estimador \(\hat\theta = \frac{\overline{X}}{1 - \overline{X}}\), no podemos obtener una expresión cerrada simple para \(Var(\hat\theta)\). ## d) ECM

Calculamos el error cuadrático medio (ECM).

Dado que el estimador no es insesgado, el ECM incluye tanto la varianza como el sesgo:

\[\begin{equation} ECM(\hat\theta) = Var(\hat\theta) + [Sesgo(\hat\theta)]^2 \end{equation}\]

Donde \(Sesgo(\hat\theta) = E(\hat\theta) - \theta\). Debido a la forma no lineal del estimador, no podemos obtener una expresión cerrada simple para el ECM y debemos calcularlo mediante métodos numéricos o de simulación.

Se elige un valor de \(\theta = 2\) y se simula una muestra aleatoria de tamaño \(n=1000\). Calculamos el estimador, graficamos el histograma de los datos y lo comparamos con la función de densidad obtenida con el parámetro estimado.

\[\begin{eqnarray} F_X(x;\theta) & = & \int_{-\infty}^{x} f(t;\theta) dt \\ & = & \int_{0}^{x} \theta t^{\theta-1} dt \\ & = & \left[t^{\theta}\right]_{0}^{x} \\ & = & x^{\theta}, \quad 0 < x < 1 \end{eqnarray}\]

Observamos que \(F_X(x;\theta)\) es estrictamente creciente en el intervalo \((0, 1)\) y por lo tanto, podemos encontrar su inversa, igualando \(U=F_X(x,\theta)\) donde \(U \sim unif(0,1)\), tenemos

\[\begin{equation} U = x^{\theta} \implies x = U^{1/\theta} \end{equation}\]

Luego, la variable aleatoria \(X=F_X^{-1}(U)=U^{1/\theta}\) tiene la misma distribución que \(X\).

Encontramos el estimador para \(\theta\) por el método de momentos.

Primero calculamos la esperanza de la variable aleatoria \(X\):

\[\begin{eqnarray} E(X) & = & \int_{0}^{\theta} x f(x;\theta) dx \\ & = & \frac{\theta}{3} \end{eqnarray}\]

Ahora igualamos la esperanza muestral a la esperanza teórica para encontrar el estimador por el método de momentos:

\[\begin{equation} \overline{X} = \frac{\hat\theta}{3} \implies \hat\theta = 3\overline{X} \end{equation}\]

Verificamos si es insesgado y/o asintóticamente insesgado.

\[\begin{equation} E(\hat\theta) = E(3\overline{X}) = 3 E(\overline{X}) = 3 \frac{\theta}{3} = \theta \end{equation}\]

Entonces, el estimador es insesgado y por lo tanto, asintóticamente insesgado.

Calculamos la varianza del estimador.

\[\begin{equation} Var(\hat\theta) = \frac{\theta^2}{2n} \end{equation}\]

Calculamos el error cuadrático medio (ECM).

Dado que el estimador es insesgado, el ECM es igual a la varianza:

\[\begin{equation} ECM(\hat\theta) = Var(\hat\theta) = \frac{\theta^2}{2n} \end{equation}\]

Se elige un valor de \(\theta = 5\) y se simula una muestra aleatoria de tamaño \(n=1000\). Calculamos el estimador, graficamos el histograma de los datos y lo comparamos con la función de densidad obtenida con el parámetro estimado.

En este caso hay que calcular la función de distribución (CDF o probabilidad acumulada)

\[\begin{eqnarray} F_X(x;\theta) & = & \int_{-\infty}^{x} f(t;\theta) dt \\ & = & \frac{2x}{\theta}- \frac{x^2}{\theta} \end{eqnarray}\]

Observamos que \(F_X(x;\theta)\) es estrictamente creciente en el intervalo \((0, \theta)\) y por lo tanto, podemos encontrar su inversa, igualando \(U=F_X(x,\theta)\) donde \(U \sim unif(0,1)\), tenemos

\[\begin{equation} U = \frac{2x}{\theta}- \frac{x^2}{\theta} \implies x = \theta - \theta \sqrt{1-U} \end{equation}\]

Luego, la variable aleatoria \(X=F_X^{-1}(U)=\theta + \theta \sqrt{1+U}\) tiene la misma distribución que \(X\).

Código 
# Parámetro fijo

theta_fijo <- 5

# Función de densidad
dexr <- function(x, theta){
  f_x <- 2*(theta-x)/(theta^2)
  return(f_x)
}

# Función para generar muestra aleatoria
rexr <- function(n, theta){
  U <- runif(n)
  X <- theta  - theta * sqrt(1-U)
  return(X)
}


# Función para estimar theta

estimar_theta <- function(X){
  theta_hat <- (3 * mean(X)) 
  return(theta_hat)
}


df_exr <- data.frame(X = rexr(5000, theta_fijo))
theta_hat <- estimar_theta(df_exr$X)
